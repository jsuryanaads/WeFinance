# Phase 3 — Wallet CRUD

Implement wallet/rekening management on top of the Phase 2 finance engine.

Scope:
- Create, edit, and delete wallets.
- Prevent deletion when a wallet is referenced by transactions.
- Opening balance is editable only as wallet master data.
- Recalculate balances from opening balance + transactions.
- Keep data local-first via localStorage.
- Preserve the Premium Dark UI.
